Text Summarizer Agent

A text-summarization agent built on Google's Agent Development Kit, with an evaluation loop, an Obsidian second brain, and optional read-only Gmail access.

Every turn is summarised into your vault as a linked note, so the notes form a graph you can browse in Obsidian. Ask the same thing again and it is answered from the vault with no model call at all.

The part most people find interesting is the evaluation loop: edit the agent's instructions, run ADK evals, and watch the score change.

Quick start

  1. Get a free key at Google AI Studio and put it in GEMINI_API_KEY in .env (./run.sh creates that file from .env.example on first run).
  2. Run it — this picks your vault, builds both containers and starts them: 
    ./run.sh
  3. Open the agent web UI on your machine at http://localhost:8001 and try a prompt.
